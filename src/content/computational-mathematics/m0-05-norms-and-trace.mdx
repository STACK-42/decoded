# Matrix Norms and the Trace

How big is a matrix? Its number of rows doesn't answer that, because a 3-by-3 matrix of tiny values and one of huge values are the same size. A **norm** reduces a matrix to one non-negative number that measures the magnitude of its entries.

## What every norm promises

There are several norms, but all the ones here share these properties, for any scalar $k$:

1. $\|A\| \ge 0$
2. $\|A\| = 0$ only when $A$ is the zero matrix
3. $\|kA\| = |k|\,\|A\|$
4. $\|A + B\| \le \|A\| + \|B\|$, the triangle inequality
5. $\|AB\| \le \|A\|\,\|B\|$

## Three norms to know

The **1-norm** is the largest absolute column sum:

$$
\|A\|_1 = \max_{j} \sum_{i=1}^{n} |a_{ij}|
$$

The **infinity-norm** is the largest absolute row sum:

$$
\|A\|_\infty = \max_{i} \sum_{j=1}^{n} |a_{ij}|
$$

A handy way to remember them: "1" is tall and thin like a column, and "∞" is short and wide like a row.

The **Euclidean norm** is the square root of the sum of every entry squared. It's Pythagoras applied to the whole matrix:

$$
\|A\|_E = \sqrt{\sum_{i=1}^{n} \sum_{j=1}^{n} a_{ij}^2}
$$

## The trace

The **trace** of a square matrix is the sum of its main diagonal:

$$
\operatorname{tr}(A) = \sum_{i=1}^{n} a_{ii} = a_{11} + a_{22} + \cdots + a_{nn}
$$

For `magic(4)`, `trace` returns $16 + 11 + 6 + 1 = 34$, which is also what every row and column of that matrix adds up to.

## In Python

```python
import numpy as np

B = np.array([[5, -4, 2], [-1, 2, 3], [-2, 1, 0]])

print(np.linalg.norm(B, 1))  # 8.0
print(np.linalg.norm(B, np.inf))  # 11.0
print(np.linalg.norm(B, "fro"))  # 8.0
print(np.trace(B))  # 7
```

The defaults differ between the two languages. With no second argument, `np.linalg.norm(B)` is the Frobenius norm, while MATLAB's `norm(B)` is the 2-norm.

pandas makes the definitions easy to read, since each one is a sum and a max:

```python
import pandas as pd

df = pd.DataFrame([[5, -4, 2], [-1, 2, 3], [-2, 1, 0]])

print(df.abs().sum(axis=0).max())  # 8
print(df.abs().sum(axis=1).max())  # 11
```

## In machine learning

Norms show up in training in several ways:

- **Regularization.** Weight decay adds the squared norm of the weights to the loss, which favours small weights. Lasso adds the sum of absolute values, which tends to push weights to exactly zero. Note that this "L1 penalty" sums all the entries, so it isn't the matrix 1-norm from this lesson.
- **Gradient clipping.** If the norm of the gradient gets too large, it's scaled back down. This keeps training stable, especially for RNNs and transformers.

```python
import numpy as np

g = np.array([30.0, 40.0])
limit = 5.0

clipped = g * min(1.0, limit / np.linalg.norm(g))
print(clipped.tolist())  # [3.0, 4.0]
```

The trace has a job too. The trace of a covariance matrix is the total variance of the data, which is what PCA divides up when it reports the share of variance each component explains.
