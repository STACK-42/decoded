# Matrices and MATLAB

A **matrix** is a rectangular grid of numbers. That plain definition covers a surprising amount of software: a photo is a matrix of pixel values, a spreadsheet is a matrix with labels, and a neural network layer is mostly a matrix of weights.

This course uses MATLAB because its syntax is close to the maths on paper. Every lesson works in MATLAB first, then shows the same ideas in Python and where they turn up in machine learning.

## Writing a matrix down

We describe size as **rows by columns**, always in that order. A 2-by-3 matrix has 2 rows and 3 columns. The entry in row $i$, column $j$ of $A$ is written $a_{ij}$.

Three shapes get their own names:

- A **column vector** is $m$-by-1.
- A **row vector** is 1-by-$n$.
- A **scalar** is 1-by-1, which is a single number.

In MATLAB, a space or comma moves to the next column and a semicolon starts a new row:

```matlab
u = [3; 1; 4]      % column vector
v = [2 0 -1]       % row vector
s = 7              % scalar
```

## Two example matrices

MATLAB ships with dozens of functions that build matrices. We'll keep coming back to two of them because they're small and easy to recognise. `pascal(3)` is **symmetric**, meaning it looks the same when you mirror it across its main diagonal. `magic(3)` isn't symmetric, but all its rows, columns and both diagonals add up to 15.

```matlab
A = pascal(3)          B = magic(3)

A =                    B =
     1     1     1          8     1     6
     1     2     3          3     5     7
     1     3     6          4     9     2
```

When you need test data, `rand` gives numbers between 0 and 1, and `fix` chops off the fractional part. This line makes a 3-by-2 matrix of random integers from 0 to 9:

```matlab
C = fix(10 * rand(3, 2))
```

## Adding and subtracting

If $A$ and $B$ are both $m$-by-$n$, their sum $C = A + B$ is also $m$-by-$n$, with

$$
c_{ij} = a_{ij} + b_{ij}
$$

Subtraction works the same way. Adding $A$ to $B$ and then subtracting $A$ brings you back to $B$, just as it does with ordinary numbers.

## Multiplying by a scalar

The scalar multiple $rA$ multiplies every entry of $A$ by $r$:

$$
c_{ij} = r \cdot a_{ij}
$$

## In Python

MATLAB is this course's main language, and each lesson also shows the Python version. NumPy arrays cover matrices, and pandas adds labelled rows and columns on top. Python counts from 0, so MATLAB's `A(1, 1)` is `A[0, 0]`.

```python
import numpy as np

A = np.array([[1, 1, 1], [1, 2, 3], [1, 3, 6]])
B = np.array([[8, 1, 6], [3, 5, 7], [4, 9, 2]])

print((A + B).tolist())  # [[9, 2, 7], [4, 7, 10], [5, 12, 8]]
print((-2 * A)[0].tolist())  # [-2, -2, -2]
```

Plain Python has no matrix type, so you'd write the loop yourself, usually with nested lists:

```python
A = [[1, 2], [3, 4]]
B = [[5, 6], [7, 8]]

C = [[a + b for a, b in zip(ra, rb)] for ra, rb in zip(A, B)]
print(C)  # [[6, 8], [10, 12]]
```

A pandas DataFrame turns into a matrix with one call:

```python
import pandas as pd

df = pd.DataFrame({"height": [170, 182, 165], "weight": [65, 80, 54]})
X = df.to_numpy()

print(X.shape)  # (3, 2)
```

## In machine learning

A training set is normally one matrix, called $X$, with one row per example and one column per feature. The DataFrame above is 3 examples with 2 features each.

Rescaling features uses this lesson's operations: subtracting a column's mean and dividing by its spread are both entry-by-entry steps. So is one step of gradient descent, $w \leftarrow w - \eta \nabla L$, a scalar multiple followed by a subtraction.
