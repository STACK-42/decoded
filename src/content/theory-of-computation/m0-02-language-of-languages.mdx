# The Language of Languages

Before any CPU or GPU was built, and before any automaton or algorithm, mathematicians needed to agree on what they were talking about. They kept running into the same problem: how do you precisely describe an infinite collection of strings with a finite set of rules?

Natural language fails here. "All strings that start with *a* and end with *b*" describes a language well enough for a person, but a machine needs something it can check mechanically. Every symbol in the notation you're about to learn exists to remove that vagueness. In short, we need a precise language for describing languages.

## The Three-Level Hierarchy

Everything in [formal language theory](https://en.wikipedia.org/wiki/Formal_language) is built on three linked concepts, and the rest of the course rests on them.

### Alphabet: $\Sigma$

An **alphabet** is a **finite, non-empty set of symbols**, where a [set](/courses/discrete-mathematics/sets#what-a-set-is) means order and repeats don't count. 

$$
\Sigma = \{a, b\}
$$

$$
\Sigma = \{0, 1\}
$$

$$
\Sigma = \{x\}
$$

The symbol $\Sigma$ (sigma) is just the conventional name. The alphabet is the raw material: the only symbols your machine is allowed to see. Think of it as the keys on a keyboard. If your keyboard only has two keys, those are the only characters you can type.

Two restrictions matter in that definition. First, $\Sigma$ must be **finite**, because a machine can only store rules for a finite list of symbols. Second, $\Sigma$ must be **non-empty**, because an alphabet with zero symbols can never build any non-empty strings. A symbol does not have to be a single letter: in a vending machine, a coin like `$5` or a token like `if` in a compiler can act as one indivisible symbol in $\Sigma$.

### String (Word)

A **string** (also called a **word**) is a **finite sequence of symbols drawn from the alphabet**. You concatenate letters, left to right, and you get a string. Unlike a set, order and repeats *do* matter in a string: $ab$ is different from $ba$, and $aa$ is different from $a$.

$$
\Sigma = \{a, b\} \implies ab,\ bba,\ aaab,\ \varepsilon\ \text{ are all valid strings}
$$

Two things to know right away. The **length** of a string $w$, written $|w|$, is the number of symbols in it, so $|abb| = 3$ and $|a| = 1$.

The other is the string that confuses everyone: the **empty string** $\varepsilon$ (epsilon), a string of zero symbols. (Some textbooks write $\Lambda$, capital lambda, for the exact same string; Module 2 uses $\Lambda$ in grammar derivations, and both mean the zero-symbol string.) Be careful, because $\varepsilon$ is not "nothing". It exists, it is a valid string over every alphabet, and it has length zero:

$$
|\varepsilon| = 0
$$

<Callout tone="orange" label="The ε mistake">
  Students often confuse the empty string $\varepsilon$ with the empty set $\emptyset$, and the language $\{\varepsilon\}$ with $\emptyset$.
  - $\varepsilon$ is a **string** of length $0$. $\emptyset$ is a **set** containing zero strings.
  - $\{\varepsilon\}$ is a **language with one string in it** ($\lvert\{\varepsilon\}\rvert = 1$), whereas $\emptyset = \{\}$ is the **empty language with zero strings** ($\lvert\emptyset\rvert = 0$).

  A language that contains $\varepsilon$ behaves very differently from one that does not. This distinction will matter in every module that follows.
</Callout>

### Language: $L$

A **language** is a **set of strings** over some alphabet. Because a language is a set, the order you list its strings in and duplicate copies do not change the language: $\{ab, ba\}$ and $\{ba, ab\}$ are the same language.

$$
L = \{ab,\ ba,\ aba\}
$$

$$
L = \{w \in \Sigma^* \mid w \text{ starts with } a\}
$$

Both of those are valid languages. One is finite and listed explicitly. The other is infinite and described by a rule (read the vertical bar $\mid$ as "such that", and $\Sigma^*$ as every possible string over $\Sigma$, defined right below). Since you can't list an infinite language, formal language theory is almost entirely about finding compact, mechanical rules that describe one.

## Kleene Star: $\Sigma^*$

You'll see this operator more than any other in the course.

The **Kleene star** $\Sigma^*$ means **all possible strings over $\Sigma$, including the empty string**: every string of every length, made from any combination of the alphabet's symbols.

You can build $\Sigma^*$ step by step by listing strings one length at a time for $\Sigma = \{a, b\}$:

- Length 0: $\varepsilon$
- Length 1: $a,\ b$
- Length 2: $aa,\ ab,\ ba,\ bb$
- Length 3: $aaa,\ aab,\ aba,\ abb,\ baa,\ bab,\ bba,\ bbb$

Combining every length gives the infinite universe of strings:

$$
\Sigma = \{a, b\} \implies \Sigma^* = \{\varepsilon,\ a,\ b,\ aa,\ ab,\ ba,\ bb,\ aaa,\ aab,\ \ldots\}
$$

$\Sigma^*$ is always infinite (because $\Sigma$ is non-empty, you can keep making longer strings forever). It is the universe of all strings your alphabet can produce.

The $+$ variant, **positive closure** $\Sigma^+$, is the same set **without** $\varepsilon$ (strings of length 1 or more):

$$
\Sigma^+ = \Sigma^* - \{\varepsilon\}
$$

<Callout tone="orange" label="What is ∅*?">
  The Kleene star also applies to any language $L$, meaning zero or more strings from $L$ joined together. Students often guess that $\emptyset^* = \emptyset$, assuming "repeating nothing gives nothing". In fact, picking **zero** strings from $\emptyset$ gives the empty string $\varepsilon$, so:
  $$\emptyset^* = \{\varepsilon\} \qquad \text{while} \qquad \emptyset^+ = \emptyset$$
  $\emptyset^*$ has one element ($\varepsilon$), whereas $\emptyset^+$ requires picking at least one string from an empty set and has none.
</Callout>

So every language $L$ you will ever study is a subset of $\Sigma^*$:

$$
L \subseteq \Sigma^*
$$

That sums up the whole hierarchy: a language is a subset of the universe of possible strings.

<Callout tone="violet" label="Why Σ* exists">
  Think of $\Sigma^*$ as your entire string universe. Without it, you would have to define what a valid string is every single time you create a language. With it, you just write $L \subseteq \Sigma^*$, and everyone instantly knows your language is a piece of that universe.
</Callout>


## Concatenation

Joining two strings end-to-end is called **concatenation**. If $u = ab$ and $v = ba$, then:

$$
uv = abba
$$

Notice that order matters: $vu = baab$, which is not the same string as $uv$. Joining any string $w$ with the empty string $\varepsilon$ leaves $w$ unchanged: $w\varepsilon = \varepsilon w = w$.

This extends to languages. The **concatenation of two languages** $X$ and $Y$ pairs every string in $X$ with every string in $Y$:

$$
XY = \{uv \mid u \in X \text{ and } v \in Y\}
$$

Let's work an example step by step with $X = \{a,\ bb\}$ and $Y = \{c,\ dd\}$:

1. Take the first string from $X$, which is $a$, and join it with each string in $Y$: $a \cdot c = ac$ and $a \cdot dd = add$.
2. Take the second string from $X$, which is $bb$, and join it with each string in $Y$: $bb \cdot c = bbc$ and $bb \cdot dd = bbdd$.
3. Collect the results into a set:

$$
XY = \{ac,\ add,\ bbc,\ bbdd\}
$$

If two pairs produce the same string, the set keeps only one copy. For example, if $X = \{a, aa\}$ and $Y = \{a, aa\}$, the pairs give $aa, aaa, aaa, aaaa$, so $XY = \{aa, aaa, aaaa\}$ (three strings, not four).

Exponents abbreviate repeated concatenation:

$$
a^3 = aaa \qquad \Sigma^2 = \{aa,\ ab,\ ba,\ bb\}
$$

And $w^0 = \varepsilon$ for any string $w$, and $L^0 = \{\varepsilon\}$ for any language $L$ (even $L = \emptyset$), since concatenating zero strings gives the empty string.

<Callout tone="orange" label="L · ∅ is not L">
  Students often treat $\emptyset$ like $0$ in addition and write $L \cdot \emptyset = L$. Concatenation works like multiplication by zero, not addition: you have to pick one string from $L$ and one string from $\emptyset$ to form every pair. Since $\emptyset$ has no strings to pair with, no pairs can be formed:
  $$L \cdot \emptyset = \emptyset \qquad \text{whereas} \qquad L \cdot \{\varepsilon\} = L$$
  The identity element for language concatenation is $\{\varepsilon\}$, not $\emptyset$.
</Callout>

## Regular Expressions: The First Compact Notation

You've probably met [regular expressions](/courses/theory-of-computation/regular-expressions#the-notation-and-what-binds-tighter) through `grep`. A **regular expression** is also a formal mathematical notation for describing [regular languages](https://en.wikipedia.org/wiki/Regular_language), invented by [Stephen Kleene](https://en.wikipedia.org/wiki/Stephen_Cole_Kleene) in 1951, and built from three operations: union, concatenation, and Kleene star.

A regular expression over $\Sigma$ is defined by three rules:

**Basis.** These are the atoms:
- $\varepsilon$ is a regular expression, describing the language $\{\varepsilon\}$
- $\emptyset$ is a regular expression, describing the empty language $\{\}$
- Any single symbol $a \in \Sigma$ is a regular expression, describing $\{a\}$

**Recursion.** If $r_1$ and $r_2$ are regular expressions, so are:
- $r_1 r_2$: concatenation (strings formed by a string from $r_1$ followed by one from $r_2$)
- $r_1 + r_2$: union (any string in $r_1$ or in $r_2$)
- $r_1^*$: Kleene star (zero or more strings from $r_1$ concatenated together)

**Closure.** Nothing else is a regular expression.

Those three rules generate every regular expression ever written. The regex in your editor, the pattern in your validation code and the search in your terminal are all instances of this recursive definition.

Write $L(r)$ for the language described by a regular expression $r$. Here is a worked example over $\Sigma = \{a, b\}$:

$$
r = a^*b^*
$$

To list $L(a^*b^*)$, pick how many $a$'s you want ($0, 1, 2, \ldots$) and how many $b$'s you want ($0, 1, 2, \ldots$):
- $0$ $a$'s and $0$ $b$'s gives $\varepsilon$
- $1$ $a$ and $0$ $b$'s gives $a$; $0$ $a$'s and $1$ $b$ gives $b$
- $2$ symbols total gives $aa, ab, bb$ (notice $ba$ is impossible, because all $a$'s must come before all $b$'s)

$$
L(a^*b^*) = \{\varepsilon,\ a,\ b,\ aa,\ ab,\ bb,\ aaa,\ aab,\ abb,\ bbb,\ \ldots\}
$$

Compare that with $(ab)^*$, where parentheses group $ab$ before applying the star:

$$
L((ab)^*) = \{\varepsilon,\ ab,\ abab,\ ababab,\ \ldots\}
$$

And with union inside the parentheses, $(a+b)^*$ chooses either $a$ or $b$ at each repetition, producing every possible string over $\{a, b\}$:

$$
L((a+b)^*) = \Sigma^*
$$

<Callout tone="orange" label="Order of operations in regular expressions">
  Kleene star ($^*$) binds tightest, then concatenation, then union ($+$). Students often misread $ab^*$ as "repeat $ab$ zero or more times". Without parentheses, the star applies only to $b$:
  - $ab^*$ means $a(b^*) = \{a, ab, abb, abbb, \ldots\}$
  - $(ab)^*$ means $\{\varepsilon, ab, abab, \ldots\}$
  - $a + bc^*$ means $a + (b(c^*))$

  Whenever you are unsure, add parentheses first.
</Callout>

> **Note:** Throughout this course, $\Sigma = \{a, b\}$ and $\Sigma = \{0, 1\}$ are interchangeable examples, since both are just two-symbol alphabets. Do not read meaning into the symbols themselves. $a$ and $b$ are placeholders, exactly like $0$ and $1$.

## Quick Reference

| Symbol         | Name              | Means                                                    |
| -------------- | ----------------- | -------------------------------------------------------- |
| $\Sigma$       | Alphabet          | Finite, non-empty set of symbols                         |
| $\varepsilon$  | Empty string      | A string of zero symbols ($\lvert\varepsilon\rvert = 0$) |
| $\emptyset$    | Empty set         | The set containing no strings                            |
| $\Sigma^*$     | Kleene star       | All strings over $\Sigma$, including $\varepsilon$       |
| $\Sigma^+$     | Positive closure  | All strings over $\Sigma$, excluding $\varepsilon$       |
| $L$            | Language          | A subset of $\Sigma^*$                                   |
| $XY$           | Concatenation     | $\{uv \mid u \in X,\ v \in Y\}$                          |

<Callout tone="mint" label="What you just built">
  You now have the three primitives that everything else in this course rests on: an alphabet defines the symbols, strings are finite sequences of those symbols, and languages are sets of strings. Regular expressions are the first tool for describing those sets compactly. Every machine you study from here (finite automata, then [pushdown automata](/courses/theory-of-computation/pushdown-automata)) is a different mechanism for deciding which strings belong to a language and which don't.
</Callout>
